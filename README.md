# Assistant — выпуски приложения

Локальная русскоязычная голосовая ассистентка для Windows и iOS. Название временное.

Исходники хранятся отдельно в закрытом `wibcoderge/Assistant-core`. Этот публичный репозиторий предназначен для готовых выпусков и описания обновлений, по той же схеме, что BART.

## Текущее состояние

Готового голосового выпуска пока нет. Первая версия `v0.1.0-alpha.1` — диагностический Windows-прототип: включение, отзыв доступа и тестовый запуск калькулятора и блокнота. Микрофон, разговорная модель, синтез речи, полное управление ПК и iOS-клиент ещё не подключены.

Распознавание, диалог и голос планируются локальными, без платных API. Файлы моделей в репозиторий выпусков не включаются.

## Сборка

В Actions вручную запускается `Build Assistant preview`. Сборщик читает конкретную версию закрытого репозитория, запускает тесты, создаёт Windows EXE и черновик предварительного выпуска с контрольными суммами. Черновик публикуется после проверки на Windows.

Для сборки требуется секрет `ASSISTANT_CORE_TOKEN`: доступ Contents: Read к одному закрытому репозиторию `Assistant-core`. Доступ к другим проектам не требуется. Пока секрет не настроен, сборку запускать не нужно.

`update-manifest.json` будет прикреплён к выпуску. Автообновление в самом приложении пока не реализовано. EXE первой версии является переносимым прототипом, а не установщиком готового ассистента.
