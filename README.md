# Assistant — выпуски приложения

Локальная русскоязычная ассистентка для Windows. Название временное, iOS-клиент запланирован.

Исходники хранятся в закрытом `wibcoderge/Assistant-core`. Этот публичный репозиторий предназначен для готовых выпусков по схеме BART.

## Состояние

Первый диагностический Windows EXE alpha.1 собран внутри закрытого проекта. В исходниках alpha.2 добавлен локальный диалог и голосовой цикл Vosk → Ollama → Silero, история сеанса и остановка звука при выключении. Проверка с реальными моделями и микрофоном на целевом ПК ещё требуется. Публичного готового голосового выпуска пока нет.

Модели загружаются отдельно. Работа планируется без платных API. Полное управление ПК, постоянная память, iOS-клиент и автообновление пока не реализованы. Доступны две команды: калькулятор и блокнот.

## Сборка

В Actions вручную запускается `Build Assistant preview`. Он читает выбранную версию закрытого репозитория, выполняет тесты, собирает Windows EXE и создаёт черновик alpha-выпуска с контрольными суммами. Публикация — после проверки на Windows.

Сборщику требуется секрет `ASSISTANT_CORE_TOKEN`: Contents: Read для одного закрытого репозитория `Assistant-core`. Пока ключ не настроен, запускать публичную сборку не нужно. Исходники, записи разговоров и файлы моделей в этот канал не загружаются.
